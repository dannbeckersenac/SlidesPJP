# Prompt da aula 2 da UC6 · o pedido das primeiras telas

Um molde para o grupo preencher e colar no Lovable, no v0 ou no assistente que já usa. Trocar cada
trecho entre `<` e `>` pelo que o grupo escreveu na Matriz CSD e ouviu na entrevista. As telas são um
rascunho para conversar com o outro grupo. Elas não são o MVP.

---

Quero um rascunho de duas ou três telas para conversar com pessoas sobre um problema. Ainda não é o
produto: é só para eu mostrar e perguntar o que a pessoa entende.

O problema: <o desafio do grupo em uma frase>
Quem tem o problema: <a pessoa, descrita sem nome, com a rotina dela em uma frase>
O momento em que o problema aparece: <a situação que a pessoa contou na entrevista>

As telas:
1. <a primeira coisa que a pessoa veria>
2. <a tela onde ela resolveria o problema>
3. <o que ela veria depois, se fizer sentido>

Regras para este rascunho:

- Telas simples, em português do Brasil, com textos curtos.
- Usar só dados fictícios, já preenchidos na tela.
- Não criar login, cadastro, pagamento nem painel administrativo.
- Os botões só precisam levar de uma tela para a outra. Não precisa salvar nada.
- No fim, me dizer como abrir as telas e como compartilhar o link.
