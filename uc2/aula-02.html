Conceito

O que um servidor web faz

1
Entrega arquivosRecebe o pedido da tela e devolve o HTML, o JavaScript e o CSS do dist/.
2
Encaminha pedidosRepassa o que começa com /api para a API e devolve a resposta.
3
Cuida do HTTPSGuarda o certificado e atende na 443. Isso entra na próxima aula.

Encaminhar esses pedidos é o papel do proxy reverso. O navegador acessa o servidor web, que chama a API.

Conceito

Navegadorpede /api/tarefas na porta 8080
→

→

Comparem os endereços da tela e da API. O protocolo, o endereço e a porta são iguais. Por isso, esses pedidos dispensam o CORS.

Para comparar · não precisam digitar

O trabalho de hoje no Nginx

nginx.conf · testado com a imagem nginx
server {
    listen 80;
    # a barra no fim do proxy_pass tira o /api do caminho
    location /api/ {
        proxy_pass http://host.docker.internal:8000/;
    }
    # o resto são os arquivos do build do React
    location / {
        root /usr/share/nginx/html;
    }
}

Leitura linha a linha

O mesmo trabalho no Caddy

exemplo do professor · Caddyfile, na raiz do repositório
# atende na porta 80, sem domínio e sem HTTPS
:80 {
    # handle_path tira o /api: /api/tarefas chega como /tarefas
    handle_path /api/* {
        reverse_proxy host.docker.internal:8000
    }
    # o resto são os arquivos do build do React
    handle {
        root * /srv
        file_server
    }
}

Conceito

Como o Caddy chega à API fora do contêiner

127.0.0.1 no contêinerAponta para o próprio contêiner. No nosso exemplo, a API está fora dele.
host.docker.internalO nome que o Docker Desktop dá, dentro do contêiner, para a máquina onde ele roda.
A API precisa aceitar conexões vindas do contêiner. Vamos iniciá-la com --host 0.0.0.0.

Recapitulando

O que vocês fizeram hoje

  • O npm run build gera o dist/. O servidor web entrega esses arquivos sem Node.
  • O endereço da API entra no build. Ele vem do .env.development ou do .env.production.
  • Variável VITE_ vai para o navegador do usuário. Segredo nunca entra nela.
  • O servidor web entrega o dist/ e encaminha o /api. Esse segundo papel é o proxy reverso.
  • Tela e API na mesma origem dispensam o CORS em produção.

Na próxima aula, vocês vão revisar os arquivos que a IA gerar para subir banco, API e Caddy juntos. Depois, vamos levar o projeto para um servidor com subdomínio e HTTPS.
