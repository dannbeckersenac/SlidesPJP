A parte que faltou

Como identificar quem fez a requisição?

Uma requisição HTTP não identifica, por si só, quem fez login antes. A API precisa receber essa identificação.

Uma tentativaO problema
mandar e-mail e senha em toda requisiçãoo front precisa guardar a senha e enviá-la a cada chamada
conferir a senha em toda requisiçãoo Argon2 é lento de propósito; a verificação atrasaria cada chamada
Precisamos identificar o usuário sem enviar a senha a cada requisição.

Conceito

O token é a pulseira do evento

Na entradaVocê apresenta o documento na entrada, como faz com e-mail e senha no login.
→
A pulseiraVocê recebe uma pulseira com identificação, validade e um lacre para conferir a origem.
→
Em cada portaNas outras portas, basta mostrar a pulseira. Quem controla o acesso confere o lacre.

A pulseira vence. No exemplo, o token vale uma hora. Ao vencer, você precisa fazer login de novo.

Conceito

As três partes de um JWT

eyJhbGciOiJIUzI1NiJ9 . eyJzdWIiOiI0IiwiZXhwIjoxNzkxMzA1NzE3fQ . h7vX9f8h6Ds8

ParteO que tem
cabeçalhoo algoritmo da assinatura: HS256
conteúdo{"sub": "4", "exp": 1791305717}: o usuário e a validade
assinaturaa assinatura feita com a chave secreta da API
O conteúdo pode ser decodificado por qualquer pessoa. Nunca coloque senha no token. A assinatura permite conferir se ele foi alterado.

Conceito

Autenticação e autorização

A perguntaQuando falha
Autenticaçãoquem é você?401: token ausente, inválido ou vencido
Autorizaçãovocê pode fazer isto?403: usuário identificado, mas sem permissão
Júlia fez login, mas seu perfil não permite lançar itens. A recusa é por falta de permissão: 403, não 401.

Na comparação com o evento: sem pulseira, você não entra. Uma pulseira de visitante também não dá acesso ao camarim.

Leitura linha a linha

Criar o token

backend/seguranca.py · os imports no topo, a função no fim
from datetime import datetime, timedelta, timezone   # data com hora, e uma duração
import jwt
from configuracao import obter_configuracao
configuracao = obter_configuracao()

def criar_token(usuario_id: int):
    validade = datetime.now(timezone.utc) + timedelta(minutes=60)  # agora mais uma hora
    dados = {"sub": str(usuario_id), "exp": validade}         # quem é, e quando vence
    return jwt.encode(dados, configuracao["chave_do_token"], algorithm="HS256")

sub e exp são nomes do padrão JWT. O sub precisa ser texto, por isso o str.

Leitura linha a linha

Validar o token

backend/seguranca.py · depois do criar_token
def ler_token(token: str):
    try:
        dados = jwt.decode(token, configuracao["chave_do_token"], algorithms=["HS256"])
    except jwt.InvalidTokenError:          # lacre falso, ou pulseira vencida
        return None
    return int(dados["sub"])                # o id de quem fez a requisição
O decode verifica a assinatura e a validade do token. Se o conteúdo for alterado, a assinatura deixa de ser válida.

A rota /login

backend/rotas/autenticacao.py · from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
router = APIRouter()
esquema_oauth = OAuth2PasswordBearer(tokenUrl="login")   # onde fica o login
@router.post("/login", response_model=Token)
def login(formulario: OAuth2PasswordRequestForm = Depends(),
          sessao=Depends(obter_sessao)):
    usuario = servico_usuario.autenticar(sessao, formulario.username,
                                         formulario.password)
    if usuario is None:                             # e-mail ou senha: a mesma resposta
        raise HTTPException(status_code=401, detail="E-mail ou senha incorretos")
    return {"access_token": criar_token(usuario.id), "token_type": "bearer"}
