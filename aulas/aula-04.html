A dor de hoje

Uma rota importando outra rota

Para calcular o total, a rota de pedidos precisava do preço. O preço está no cardápio, e o cardápio mora dentro da rota de itens.

exemplo do professor · backend/rotas/pedidos.py, primeiras linhas
from fastapi import APIRouter, HTTPException
from esquemas.pedido import PedidoCriar, PedidoSaida
from rotas.itens import cardapio   # o cardápio mora lá dentro
No ciclo 2 esse cardápio vem do banco. Quando isso acontecer, as duas rotas mudam, e toda rota que tiver importado a lista muda junto.

Analogia

Ninguém pede pizza para o estoquista

O salãoO garçom anota o pedido e leva a resposta de volta. Ele não cozinha.
→
A cozinhaDecide como o prato é montado e faz a conta do que vai sair.
→
A despensaGuarda o que tem e entrega quando pedem. Não decide nada.
O garçom não sabe onde fica o saco de farinha, e a despensa não sabe o nome do cliente. É isso que a gente vai fazer com o código de hoje.

Conceito

As três camadas

Cada camada é uma pasta, e cada pasta faz uma coisa só.

1
Rotarotas/ fala HTTP: lê o caminho, chama o serviço, escolhe o status e devolve JSON.
2
Serviçoservicos/ decide: junta os dados, faz as contas e monta o que vai ser guardado.
3
Repositóriorepositorios/ guarda: entrega e grava o dado, sem saber para que serve.

A direção é sempre a mesma: a rota chama o serviço, o serviço chama o repositório. Nunca ao contrário.

Referência

O que pode aparecer em cada pasta

PastaPode usarNunca aparece nela
rotas/APIRouter, HTTPException, status, esquemasa lista de dados, a conta do total
servicos/os repositórios, os esquemas, as contasHTTPException, status, APIRouter
repositorios/a lista em memória, o for que procuraconta, regra, HTTPException
A regra em uma frase: a rota não toca no dado, e o serviço não sabe o que é 404.

A terceira dor de hoje

O mesmo 404, em toda rota que tem id

Ver um pedido
@router.get("/{pedido_id}")
def obter_pedido(pedido_id: int):
    p = servico.buscar_por_id(pedido_id)
    if p is None:
        raise HTTPException(
            status_code=404,
            detail="Pedido não encontrado")
    return p
Cancelar um pedido
@router.delete("/{pedido_id}")
def apagar_pedido(pedido_id: int):
    p = servico.buscar_por_id(pedido_id)
    if p is None:
        raise HTTPException(
            status_code=404,
            detail="Pedido não encontrado")
    servico.apagar(p)
    return {"apagado": pedido_id}

O miolo das duas é igual, e vai se repetir no PUT. Cada rota nova com id copia o mesmo bloco.

Conceito

Depends: a rota pede, o FastAPI entrega

Em vez de a rota buscar o pedido, ela declara que só roda se um pedido existente chegar pronto. Quem providencia é o FastAPI.

1
Você escreveUma função comum que faz o trabalho e devolve o que a rota vai usar.
2
A rota declaraUm parâmetro com Depends(funcao) no lugar do valor.
3
O FastAPI resolveChama a função antes da rota e entrega o resultado no parâmetro.

Guarde esta peça: no ciclo 2 é ela que vai entregar a conexão com o banco a cada requisição.

Mão na massa · passo 7 de 7

A busca vira uma dependência

backend/rotas/pedidos.py · from fastapi import Depends
def pedido_existente(pedido_id: int):     # função comum, fora de rota
    pedido = servico.buscar_por_id(pedido_id)
    if pedido is None:
        raise HTTPException(status_code=404, detail="Pedido não encontrado")
    return pedido
@router.get("/{pedido_id}", response_model=PedidoSaida)
def obter_pedido(pedido=Depends(pedido_existente)):
    return pedido
  1. Escreva a função no arquivo de rotas, logo depois do router.
  2. Nas rotas com id, troque o parâmetro por pedido=Depends(pedido_existente).
  3. Teste /pedidos/1 e /pedidos/99. O 404 continua, escrito uma vez só.

Recapitulando

O que fica da aula 4

  • Rota fala HTTP, serviço decide, repositório guarda. Uma responsabilidade por pasta.
  • A chamada vai sempre em uma direção: rota, serviço, repositório.
  • O serviço devolve None. Quem transforma isso em 404 é a rota.
  • O que muda de máquina vive no .env, e o .env não vai para o Git.
  • Depends escreve uma vez só o que várias rotas repetiam.
