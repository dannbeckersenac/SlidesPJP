Google · google-genai

Anthropic · anthropic

A dor

E se a cota acabar na apresentação?

Imaginem que o Gemini devolva 429 durante a apresentação de quinta. A cota acabou e o pedido ficou sem resposta.

Vamos configurar outras opções para tentar responder quando o Gemini estiver indisponível.

Conceito

Fallback: tentar outro provedor

Geminio principal, grátis
→
OpenRoutera primeira reserva, grátis
→
Claudea terceira opção, paga, só quando as outras falham

O código tenta as reservas na ordem. Se uma responder, podemos conferir o provedor em resposta.provider.

Referência

Quais erros acionam a reserva

Erro no provedor atualO Jangada faz
limite (429), demora, conexão, erro 5xxtenta de novo, depois passa para o próximo
modelo que não existe (404)passa para o próximo direto
chave inválida ou pedido errado (400)devolve o erro, sem passar adiante

As novas tentativas aumentam a espera. O fallback pode falhar também se nenhuma reserva conseguir responder.

Segurança

A chave do Claude é paga

O professor fornece a chave. Os pedidos ao Claude são cobrados, por isso ele fica depois das duas opções grátis.

A ANTHROPIC_API_KEY fica só no backend/.env. Nunca no Git, no frontend, num print ou na conversa com a IA.

Se a chave aparecer num lugar público, avisar o professor para revogá-la e criar outra.

from jangada_ai import LLM
import configuracao
gemini = LLM("gemini", "gemini-3.8-flash", api_key=configuracao.chave_do_gemini)
# a primeira reserva: um modelo grátis escolhido pelo OpenRouter

claude = LLM("anthropic", "claude-opus-5-5", api_key=configuracao.chave_do_claude)
llm = gemini.with_fallback(openrouter, claude)

Conceito

Tool: pedir a execução de uma função

Para consultar um prazo ou um dado do banco, o modelo precisa receber essa informação. Uma tool permite pedir essa consulta ao código.

Perguntacom a lista de tools
→
A IA pede"rodar dias_ate com este prazo"
→
O código rodae devolve o resultado
→
Respostausando o resultado

Nas funções do projeto, o backend executa a consulta. O modelo pede a função e informa os argumentos.

Referência

Três tipos de tool

TipoExemplosCuidado
Prontas do Jangadaconsultar_cep, feriados_nacionais, wikipedia_search, calculatornão pedem chave
Nativas do provedorweb_search(): no Gemini, a busca do Googlegastam cota e trazem fontes
Funções de vocêscontar dias, ler um dado do sistematipos e docstring obrigatórios

A docstring descreve o que a função faz e quais dados recebe. O modelo usa essa descrição para decidir quando chamá-la.

Mão na massa · passo 8 de 10

Criar as tools da funcionalidade

exemplo do professor · backend/ia/ferramentas.py
from datetime import date
from jangada_ai.prebuilt import feriados_nacionais

# uma tool feita à mão: a docstring é o que a IA lê para decidir quando usar
def dias_ate(prazo: str) -> int:
    """Conta quantos dias faltam de hoje até o prazo, no formato AAAA-MM-DD."""
    return (date.fromisoformat(prazo) - date.today()).days

FERRAMENTAS = [dias_ate, feriados_nacionais]
  1. Criar backend/ia/ferramentas.py com as tools escolhidas para a funcionalidade.
  2. Montar a lista FERRAMENTAS com as tools escolhidas. O exemplo usa uma pronta e uma função do professor.

Mão na massa · passo 9 de 10

Criar a função que chama o Agent

exemplo do professor · backend/ia/sugestao.py
from jangada_ai import Agent
from ia.modelos import llm
from ia.ferramentas import FERRAMENTAS
INSTRUCAO = """Sugira de 3 a 6 etapas para o checklist desta tarefa.
Use as ferramentas para ver os dias até o prazo e os feriados.
Responda com uma etapa por linha, começando com um verbo."""
# o agente chama as tools quando precisa e devolve o texto final
def sugerir_etapas(titulo, descricao, prazo):
    agente = Agent(llm, role="assistente", goal=INSTRUCAO, tools=FERRAMENTAS)
    entrada = f"Título: {titulo}\nDescrição: {descricao}\nPrazo: {prazo}"
    return agente.run(entrada).text
  1. Criar o arquivo da funcionalidade em backend/ia/. Usar a instrução do seu ia.md e os campos do seu projeto.

Ligar a funcionalidade a uma rota

exemplo do professor · backend/rotas/tarefas.py
from ia.sugestao import sugerir_etapas
# POST: cada pedido gasta cota e a resposta muda. Nada é gravado aqui
@router.post("/{tarefa_id}/sugestoes")
def sugerir(tarefa=Depends(tarefa_existente)):
    try:
        etapas = sugerir_etapas(tarefa.titulo, tarefa.descricao, str(tarefa.prazo))
        return {"sugestao": etapas}
    except Exception:
        raise HTTPException(status_code=503, detail="Sugestão indisponível agora.")

  2. Executar fastapi dev main.py, chamar a rota no /docs e conferir o 200 com a sugestão.

Segurança

Limitar o que as tools podem fazer

  1. Criar tools que apenas leem ou calculam. Deixar a gravação, a exclusão e o envio sob controle da pessoa.
  2. Validar os argumentos. Testar, por exemplo, uma data inválida e conferir o tratamento do erro na rota.
  3. Restringir o acesso da tool aos dados permitidos para o usuário, sem expor senhas ou chaves.
  4. Testar com dados fictícios. O plano grátis usa o que é enviado.
